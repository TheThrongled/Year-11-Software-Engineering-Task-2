### Project Vision
This project translates strategic thinking, character progression, and RPG style combat into an Object-Oriented Programming (OOP) framework in Python. 

#### Core Gameplay Loop
* **Actions**: Movements are based on direct attack and movement on a turn based level.
* **Strategic Combat**: Enemies have various waves and the player's abilities are centred around the dismantling of enemies waves. They may kill the player and as the player gets more strength he must continually get the furthest.
* **Progression**: After defeating enemies using a combination of exploration and combat, there will be pills to consume and get stronger.

### How to run
Get python and install the tcod library (eg. in terminal type "pip3 install tcod"), then in terminal do python3 main.py (in same folder as where you downloaded it)
